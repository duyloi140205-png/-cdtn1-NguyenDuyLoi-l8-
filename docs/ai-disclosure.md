# AI DISCLOSURE

## 1. Công cụ AI sử dụng
* **ChatGPT / Gemini:** Hỗ trợ tư vấn thiết kế kiến trúc, sinh mã Mermaid, viết SQL DDL và xử lý lỗi Git.
* **GitHub Copilot / VS Code:** Hỗ trợ gợi ý cú pháp và quản lý file.

## 2. Các công việc AI đã hỗ trợ
* **Sửa lỗi Git:** Khắc phục lỗi `fatal: not a git repository` và hướng dẫn câu lệnh push code.
* **Sơ đồ ERD & SQL:** Thêm bản số (1-1, 1-N), tạo mã Mermaid ERD và sinh file SQL DDL Skeleton (`docs/sql-ddl.sql`).
* **Sơ đồ Kiến trúc:** Tạo sơ đồ phân lớp, phân định ngoài phạm vi (Outside Scope) và viết 3 câu lập luận NFR.
* **Wireframe:** Dựng 3 màn hình giao diện (Danh sách, Trả lời khảo sát CSAT/NPS, Dashboard).
* **Đóng gói báo cáo:** Hướng dẫn cấu trúc xuất báo cáo PDF chuẩn theo yêu cầu.
